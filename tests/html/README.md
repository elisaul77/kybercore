# 🧪 Tests HTML

Archivos HTML de prueba y demostración para KyberCore.

## 📁 Archivos

### `gcode_viewer_demo.html`
- **Propósito**: Demo del visor de G-code 3D
- **Uso**: Abrir directamente en el navegador
- **Estado**: ✅ Funcional

### `test_routing.html`
- **Propósito**: Pruebas de sistema de routing de URLs
- **Uso**: Verificar navegación entre vistas
- **Estado**: ✅ Funcional

### `wizard_verification.html`
- **Propósito**: Verificación del wizard de impresión (7 pasos)
- **Uso**: Validar flujo completo del wizard
- **Estado**: ✅ Funcional

### `debug_cards.html`
- **Propósito**: Debug de componentes de tarjetas
- **Estado**: 🔍 Revisar si aún se usa

## 🚀 Cómo Usar

```bash
# Abrir demo del visor de G-code
open tests/html/gcode_viewer_demo.html

# Verificar routing
open tests/html/test_routing.html

# Validar wizard
open tests/html/wizard_verification.html
```
